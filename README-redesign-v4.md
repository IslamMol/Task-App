# Task App — Grid Clarity v4

Редизайн карточек привычек, дел/квестов и книг.

Изменения:
- новые карточки entry с единым визуальным языком;
- streak-статистика и состояние выполнения для привычек;
- отдельное состояние квестов и дел;
- книжная карточка с прогресс-баром и текущим прогрессом;
- улучшенные empty states;
- адаптивные стили для мобильных экранов.

Логика Supabase, IndexedDB и синхронизации не менялась.
